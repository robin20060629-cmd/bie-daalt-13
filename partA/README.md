## 🛠️ Архитектурын үндсэн шийдвэрүүд

### 1. Database: SQLite + FTS5
Төслийн гол шаардлага болох "Full-text search"-ийг хамгийн хурдан бөгөөд хөнгөн байдлаар шийдэхийн тулд SQLite-ийн **FTS5** (Full-Text Search) виртуаль хүснэгтийг ашиглахаар шийдсэн. Энэ нь нэмэлт хайлтын сервис (Elasticsearch гэх мэт) ашиглах шаардлагагүй болгосон.

### 2. Frontend & Backend Integration
React (Frontend) болон Node.js (Backend) хооронд **REST API** ашиглан харилцахаар төлөвлөсөн. Өгөгдлийн бүрэн бүтэн байдлыг хангах үүднээс `better-sqlite3` санг сонгосон.

## 🤖 AI Collaboration Workflow

AI-г (Claude) дараах байдлаар ашигласан:
* **Initial Brainstorming:** Төслийн бүтцийг хэрхэн цэгцтэй байлгах талаар зөвлөгөө авсан.
* **Refining Decisions:** Архитектурын шийдвэр гаргахад (ADR) боломжит сул талуудыг шүүмжлүүлсэн.
* **Documenting:** Бичиг баримтуудыг мэргэжлийн түвшинд найруулах.
