## 1. Хэрэв шалгалт өнөөдөр болбол би энэ кодыг өөрөө бичиж чадах уу?

**Хэсэгчлэн — тайлбартай.**

Чадах:
- Express REST API бүтэц, middleware тохиргоо
- SQLite-тай basic CRUD хийх
- Jest + supertest тест бичих
- React компонент, `fetch` API дуудах

Хэцүү байх:
- **SQLite FTS5 trigger syntax** — AI-аас сурсан боловч гараар бичихэд documentation шалгах хэрэгтэй болно. Энэ бол шинэ мэдлэг.
- **`html-pdf-node` API** — deprecated package-ийн нөлөөгөөр цаг алдсан. Дахин хийхэд шууд зөв library сонгох байсан.
- **FTS5 `snippet()` функц** — тестэд хэрэглэсэн боловч бүрэн ойлгоогүй хэсэг байна.

**Дүгнэлт:** Суурь ойлголттой болсон боловч SQLite advanced feature-үүд дээр илүү гүнзгий сурах хэрэгтэй.

## 2. Дахин хийнэ гэвэл юуг өөрөөр хийх вэ?

**1. AI-д асуухаасаа өмнө өөрөө туршиж үзнэ.**  
Деплой, package сонголт, тохиргоо зэрэгт шууд AI-д хандсан. Дараагийн удаа эхлээд official documentation уншаад, ойлгоогүй хэсгийг л AI-аас асууна.

**2. AI session log-г бодитоор хадгалах.**  
Бие даалтын дагуу session log хадгалсан боловч зарим чухал яриа хадгалагдаагүй. Дараагийн удаа тодорхой асуулт, хариулт бүрийг тэмдэглэнэ.

**3. Feature branch ашиглах.**  
`main` branch дээрээ шууд commit хийсэн. Дараагийн удаа `feat/pdf-export`, `feat/search` гэх мэт branch ашиглана — энэ нь Git history-г уншихад хялбар болгоно.

**4. Тестийг эрт бичих (TDD).**  
Код бичсэний дараа тест бичсэн. TDD хийвэл edge case-г эртнээс харж, илүү зөв бүтэц гарах байсан.
